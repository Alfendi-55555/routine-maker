## 4. 사용법

> 초안입니다. 배포된 화면을 보면서 본인 말로 다듬어 주세요.

**핵심 흐름: 고정 일정 넣기 → 루틴 만들기 → 오늘 시작하고 끝내기 → 기록 보기**

1. 공개 주소를 엽니다. 처음이면 오늘 탭에 "아직 고정 일정이 없어요" 안내가 나옵니다.
2. **캘린더** 탭 아래 **+ 고정 일정 넣기**로 수업·통학·알바처럼 매주 반복되는 고정 일정을 넣습니다(이름, 종류, 요일, 시작·끝 시각). 주 보기에 회색 칸으로 표시됩니다.
3. **루틴** 탭 맨 위 **+ 새 루틴 만들기**를 누르면 창이 열립니다. 이름·색 → 루틴 종류 → 언제·얼마나 자주 → 시간·분량 순서로, 앞 단계를 정하면 다음 단계가 아래에 나타납니다. 루틴 종류는 세 가지입니다.
   - **시각 루틴**: 정해진 시각에 (요일을 정하거나 주 몇 번)
   - **상황 루틴**: 고정 일정이 끝나면 / 다른 루틴을 끝내면 / 쉬는 날이면 / 내가 알려 주는 상황이 되면 (상황이 올 때마다)
   - **아무 때나 루틴**: 빈 시간 아무 때나 (요일을 정하거나 주 몇 번)
4. **오늘** 탭에서 빈 시간과 오늘 할 루틴을 확인하고 **시작**을 누릅니다. 위쪽 "하는 중" 카드에 타이머가 돌고, 막대 위 눈금이 최소 시간입니다. 새로고침해도 이어집니다.
5. 끝나면 **끝냈어요**를 누릅니다. 최소 시간을 넘기면 한 번으로 셉니다. 최소 시간 전에 끝내려 하면 한 번 묻고, 그래도 끝내면 기록만 남고 횟수·연속에는 세지 않습니다(늘 같은 분량인 루틴은 분량을 끝내면 셉니다). 분량이 매번 다른 루틴은 분량(예: 슬라이드 장수)을 입력합니다.
6. 루틴 이름을 누르면 **루틴 상세**가 열립니다. 오늘 할 차례와 시작, 이번 주·연속·최고 기록, 규칙, 지난 5주 달력, 걸린 시간 변화, 이 루틴에 대한 제안, 이 루틴의 기록 전부(10개씩 더 보기)가 한 화면에 있습니다(주소 `#routine-<id>`).
7. **돌아보기** 탭은 **이번 주 돌아보기**입니다. 루틴 실천 횟수, 루틴에 쓴 시간, 다른 활동의 예상 대비 실제, 가장 긴 연속을 지난주와 나란히 보고, 루틴별 표와 그 주의 다른 활동, 카테고리별 배율(실제 ÷ 예상)을 봅니다. 화살표로 지난주들도 볼 수 있습니다. 기록이 3개 쌓이면 오늘 탭의 예상 시간이 실제에 맞게 보정됩니다.

그 밖의 기능

- **캘린더** 탭: 기본은 **주 보기**로, 시간표처럼 고정 일정(회색)·한 루틴(루틴 색)·할 차례(점선)를 봅니다. **월 보기**로 바꾸면 공휴일과 기록한 날(루틴 색 점)을 봅니다. 날짜를 누르면 그날 고정 일정과 기록이 아래에 나옵니다.
- **넓은 화면(1024px 이상)**에서는 왼쪽 메뉴와 여러 칸 배치로 바뀝니다. 오늘은 시간 막대 아래 지금·남은 루틴과 이번 주·제안을 나란히, 캘린더는 주 보기 옆에 고른 날과 고정 일정을, 루틴은 목록과 상세를 나란히, 돌아보기는 기록 옆에 제안·배율을 둡니다. 휴대폰 화면은 그대로입니다.
- 루틴마다 **색**이 있습니다(8가지, 앱의 청록·회색과 겹치지 않음). 캘린더·오늘 탭·루틴 상세에서 같은 색으로 보입니다.
- 오늘 탭의 **다른 활동 기록하기**: 과제처럼 루틴이 아닌 일을 재거나, 이미 끝낸 일을 직접 입력합니다.
- 오늘 탭의 **상황 버튼**(예: 집 도착): 내가 알려 주는 상황 루틴이 있으면 생깁니다. 누르면 연결된 루틴이 오늘 할 일로 올라옵니다.
- 새 루틴 만들기 2단계의 **물음표 아이콘**에서 루틴 종류 세 가지(시각 · 상황 · 아무 때나)를 예시와 함께 볼 수 있습니다.
- 루틴·고정 일정·기록은 **연필 아이콘**으로 고치고, 지우기는 고치기 창 안에서 합니다. 지운 기록은 바로 되돌릴 수 있습니다.
- 오른쪽 위 **톱니바퀴(설정)**: 하루 설정, 공휴일 설정, 기록 관리(내보내기·가져오기·전체 삭제)
- 돌아보기의 **루티의 제안**: 기록을 보고 횟수·요일·기본 시간·최소 시간을 다듬자고 제안합니다. "왜 이 제안이에요?"로 기준과 숫자를 볼 수 있습니다.
- 둘러보기만 하려면 설정(톱니바퀴) › 기록 관리의 **예시 데이터로 둘러보기**를 누릅니다(데이터가 하나도 없을 때만 보임).

## 5. 데이터 출처와 갱신일

| 데이터 | 출처 | 이용 조건 | 갱신 | 쓰는 곳 |
|---|---|---|---|---|
| 공휴일 | [한국천문연구원_특일 정보](https://www.data.go.kr/data/15012690/openapi.do) · 공휴일 정보 조회(getRestDeInfo), 공공데이터포털 | 이용허락범위 제한 없음, 무료 (2026-10-16 포털 페이지에서 확인) | 매달 1일 GitHub Actions가 올해·내년 공휴일을 받아 `data/holidays.json`에 저장. 마지막 갱신일은 앱의 설정(톱니바퀴) › 공휴일 설정에 표시 | 공휴일에는 고른 종류(기본 수업·통학)의 고정 일정을 빼고 빈 시간 계산, 캘린더에 표시 |
| 사용자 기록 | 사용자가 직접 입력 | - | 입력할 때마다 | 브라우저 `localStorage`(키 `routinemaker.v1`)에만 저장 |

- 인증키는 GitHub Secrets(`DATA_GO_KR_KEY`)에만 두고 GitHub Actions에서만 씁니다. 앱(브라우저)은 저장소에 커밋된 `data/holidays.json`만 읽으므로 키가 공개되지 않습니다.
- 이름·이메일 같은 개인 식별 정보를 받지 않습니다. 기록은 서버로 보내지 않고, 로그인·외부 글꼴·분석 도구도 없습니다.
- 문서 갱신일: 2026-10-17

## 개발자용

- 구조: `index.html`, `style.css`, `js/calc.js`(계산), `js/store.js`(저장), `js/sample.js`(예시 데이터), `js/app.js`(화면)
- 빌드 도구·외부 라이브러리 없음. `index.html`을 더블클릭해도 동작합니다.
- 계산 테스트: `node --test tests/`
- GitHub Pages: `main` 브랜치 루트에서 배포 (Settings → Pages)
- 공휴일 데이터 설정
  1. [공공데이터포털](https://www.data.go.kr/data/15012690/openapi.do)에서 "한국천문연구원_특일 정보" 활용 신청 → 마이페이지에서 **일반 인증키(Decoding)** 복사
  2. 저장소 Settings → Secrets and variables → Actions → New repository secret: 이름 `DATA_GO_KR_KEY`, 값은 위 키
  3. Actions 탭 → "공휴일 갱신" → Run workflow (처음 한 번). 이후 매달 1일 자동 실행
  - 로컬에서 직접 받기: `DATA_GO_KR_KEY=<키> node scripts/fetch-holidays.js`
  - 파일로 연 `index.html`에서는 브라우저 보안 때문에 공휴일 파일을 못 읽습니다. 배포된 주소나 로컬 서버에서 확인하세요.
